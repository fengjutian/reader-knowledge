# Voyage 风格主题生成提示

> 参考来源：[Voyage AI](https://www.voyageai.com/)。本提示仅提炼其视觉语言，不复制商标、文案、插画或页面结构。

## 主提示词

为一个桌面端中文阅读知识库设计名为「航行 Voyage」的新主题。整体气质应自然、理性、轻盈，带有古典出版物与前沿 AI 产品交融的研究感，但仍适合长时间阅读。

使用大面积极浅薄荷绿色纸面背景、墨绿色正文与深青绿色作为核心交互色。背景加入两组原创手绘水彩星云：左上与右下分布，使用青蓝、酒红、铜金、墨绿与少量粉色，保留湿边、颗粒和飞溅纹理，中央信息区保持留白。组件使用暖白半透明表面、1px 灰绿色描边、柔和阴影与 14–18px 圆角。

标题使用典雅高对比衬线字体与宽松层级，正文使用清晰的现代无衬线字体。主按钮使用深墨绿色胶囊感表面，悬停时加深并微微上浮；图标容器使用淡草绿色。侧栏保持浅薄荷色磨砂质感，当前导航项使用淡绿底和墨绿文字。数据进度条从深青绿渐变至橄榄绿。动效仅使用 150–250ms 的位移、透明度和阴影变化，并尊重 `prefers-reduced-motion`。

必须保证：正文对比度达到 WCAG AA；背景装饰不承载信息；输入框、弹窗、知识图谱、卡片、按钮、导航、空状态都使用同一套设计令牌；保留产品原有信息架构和中文内容；不要出现 Voyage AI 的 logo、品牌名称、原站文案或原站插画。

## 设计令牌

```css
--bg:#f7f8ff; --surface:rgba(255,255,255,.86); --surface-hover:#edf0ff;
--text:#101122; --secondary:#62677d; --muted:#9196aa; --border:#dfe3f1;
--accent:#5c5ce2; --accent-soft:#ececff;
--glow-pink:rgba(240,139,195,.24); --glow-blue:rgba(126,153,255,.20); --glow-mint:rgba(115,220,214,.15);
```

## 验收要点

- 首屏能明显感受到冷白、蓝紫和柔焦光晕组成的主题个性。
- 卡片内容区清晰，玻璃效果不会降低可读性。
- 主题覆盖所有页面，而非只修改首页。
- 与默认纸张主题、深色主题可切换并持久化保存。
- 不使用第三方品牌素材，视觉结果具有独立性。
