# wereader 产品规划

## 当前范围

### 书籍元数据

- 当前仅开放豆瓣作为书籍元数据补全来源。
- 支持单本补全与批量补全。
- 批量补全每次最多选择 10 本书，按书名与作者逐本检索并保存结果。
- 单本失败不应中断整批任务；完成后展示成功与失败数量。

## 后期规划

### 扩展元数据来源

- 重新评估并开放 Open Library。
- 重新评估并开放 Google Books。
- 开放前补充来源优先级、字段冲突合并、匹配可信度、请求限流和 API Key 配置方案。
- 在上述方案确定前，产品界面隐藏 Open Library 与 Google Books 的选择入口及历史来源展示，但保留底层实现以便后续启用。
